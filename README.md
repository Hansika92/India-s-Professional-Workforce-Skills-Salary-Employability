# India’s Professional Workforce: Skills, Salary & Employability

## Project Overview

This project analyzes professional workforce data from India to understand
how experience, skills, seniority, education, certifications and generative
AI adoption are associated with salary and employability.

The analysis combines Python, SQL and Power BI to demonstrate an end-to-end
data analytics workflow.

## Business Questions

- How does professional experience relate to salary?
- How does salary vary across seniority levels?
- Which skill domains have higher median salaries?
- Which professional skills are most common?
- Is skill count associated with employability?
- How prevalent is generative AI adoption?
- What skills are most common among Data Analysts?
